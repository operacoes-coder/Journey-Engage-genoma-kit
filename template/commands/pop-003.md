---

Executar POP-003 (Autocorrecao de Erros) para o seguinte problema:

$ARGUMENTS

Procedimento:
1. **Detectar:** Qual e o erro exato? Warning ou erro bloqueante?
2. **Diagnosticar:** Identificar causa RAIZ, nao apenas sintoma
3. **Classificar:** Posso resolver sozinho?

**Se SIM (correcoes seguras):**
- Erros de Git (case sensitivity, staging, line endings)
- Arquivos recriaveis
- Erros de sintaxe em arquivos que eu criei
- Warnings que nao impedem operacao
-> Corrigir imediatamente, informar o que fiz

**Se NAO (requer decisao humana):**
- Erros em dados de producao
- Conflitos de merge com codigo de terceiros
- Falhas de credenciais/permissoes
- 2+ caminhos validos com consequencias diferentes
-> Apresentar no formato:
```
PROBLEMA: [descricao clara]
CAUSA: [por que aconteceu]
OPCOES:
  A) [acao] — [consequencia]
  B) [acao] — [consequencia]
RECOMENDACAO: [opcao e justificativa]
```

**Anti-Loop:** Se mesma correcao falhar 2x -> parar e apresentar opcoes.
