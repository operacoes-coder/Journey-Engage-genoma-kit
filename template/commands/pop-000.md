Executar POP-000 (Diagnostico de Inicio de Sessao) AGORA.

Procedimento OBRIGATORIO — executar TODOS os passos em sequencia:

1. Ler `CLAUDE.md` — regras e estrutura do projeto
2. Ler `.context/SNAPSHOT.md` — estado atual completo
3. Executar `git log --oneline -10` — timeline recente
4. Executar `git status` — verificar mudancas nao commitadas
5. Se `.env` existe — verificar credenciais disponiveis
6. Ler ultimo historico de sessao (se existir pasta de historicos)

Apos coletar TUDO, gerar relatorio proativo:
- Analisar TODAS as informacoes coletadas (SNAPSHOT, historicos, git log, docs)
- Identificar o que e CRITICO, o que esta ATRASADO, o que esta BLOQUEADO
- Priorizar por: urgencia > criticidade > dependencias > impacto
- Incluir proximos passos concretos e acionaveis
- Adaptar formato ao estado real do projeto (sem template fixo)

Finalizar perguntando: "Qual sera o foco desta sessao?"
