description: "POP-002: Checkpoint Mid-Session — salva estado intermediario sem interromper o trabalho"
---

Executar POP-002 (Checkpoint Mid-Session) AGORA.

Determinar o tipo de save necessario baseado no argumento ou contexto:
- Argumento: $ARGUMENTS (LIGHT, FULL ou SAFETY)
- Se nao especificado, avaliar automaticamente qual tipo e necessario

**LIGHT** (mudancas pequenas):
1. Atualizar `.context/SNAPSHOT.md` secao "Context to Resume" apenas
2. `git add .context/SNAPSHOT.md && git commit -m "checkpoint(light): [motivo]"`

**FULL** (decisao importante ou ~15 trocas):
1. Atualizar `.context/SNAPSHOT.md` completo
2. Se houve decisao -> atualizar `.context/DECISIONS.md`
3. `git add .context/ && git commit -m "checkpoint(full): [motivo]"`

**SAFETY** (antes de acao arriscada ou ~25 trocas):
1. Executar POP-001 completo
2. `git commit -m "checkpoint(safety): save point before [acao]"`

Informar: "Checkpoint [$TIPO] salvo: [motivo]"
