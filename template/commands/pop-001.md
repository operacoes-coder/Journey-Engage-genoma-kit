Executar POP-001 (Save de Sessao / Protecao Anti-Compressao) AGORA.

PRIORIDADE ABSOLUTA — parar qualquer tarefa em andamento e executar:

1. `git status` — verificar mudancas nao commitadas
2. Commitar TUDO pendente com conventional format
3. Atualizar `.context/SNAPSHOT.md` completo e AUTOCONTIDO:
   - `## Session` — Numero, data, ultimo commit hash
   - `## Module Status` — Cada modulo com status + % + detalhe do que falta
   - `## In Progress` — Checklist [x] feito e [ ] pendente
   - `## Next Steps` — Priorizado por urgencia > criticidade > dependencia
   - `## Context to Resume` — BLOCO CRITICO: tudo que o proximo agente precisa saber
     para retomar SEM precisar ler outros arquivos
   - `## Pending Triggers` — POPs que devem ser verificados
   - `## Recent Activity` — Ultimos commits com data e hash
4. Criar/atualizar historico de sessao (se aplicavel ao projeto)
5. `git add` todos os arquivos alterados + .context/
6. `git commit -m "session(save): session NNN - [resumo]"`
7. Informar: "Checkpoint salvo. Contexto preservado para continuidade."

Se foi chamado por $ARGUMENTS (AMARELO, LARANJA, VERMELHO), incluir nivel no commit.
