description: "POP-001: Save de Sessao — salva contexto, historico, tasks e decisoes"
---

Executar POP-001 (Save de Sessao / Protecao Anti-Compressao) AGORA.

PRIORIDADE ABSOLUTA — parar qualquer tarefa em andamento e executar:

**Fase 1: Commitar Trabalho**
1. `git status` — verificar mudancas nao commitadas
2. Commitar TUDO pendente com conventional format

**Fase 2: Decisoes**
3. Revisar sessao — houve decisoes nao registradas?
4. Se sim: registrar em `.context/DECISIONS.md` com timestamp real (`date +%Y-%m-%d`, `date +%H:%M`)

**Fase 3: Historico de Sessao**
5. Obter timestamp: `date +%Y-%m-%d-%H%M`
6. Criar `.context/history/session-NNN-YYYY-MM-DD-HHmm.md` com:
   - Horarios reais (inicio/fim)
   - Concluido, pendente, decisoes, erros, metricas
   - Contexto completo para proxima sessao

**Fase 4: Tasks**
7. Tasks DOING nao concluidas → mudar para TODO
8. Tasks DONE → mover para "Concluidas"
9. Tasks novas identificadas → criar em tasks/

**Fase 5: SNAPSHOT**
10. Atualizar `.context/SNAPSHOT.md` COMPLETO e AUTOCONTIDO:
    - Module Status, In Progress, Tasks Pendentes, Planos Ativos
    - Next Steps repriorizados
    - Context to Resume (DOING/BLOCKED_BY/NEXT_ACTION/LAST_SESSION)
    - Recent Activity com timestamp real

**Fase 6: Commit de Sessao**
11. `git add` todos os arquivos GENOMA
12. `git commit -m "session(save): session NNN - [resumo]"`
13. Informar: "Checkpoint salvo. Contexto preservado."

Se chamado por $ARGUMENTS (AMARELO, LARANJA, VERMELHO), incluir nivel no commit.
