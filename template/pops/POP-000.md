# POP-000: Diagnostico de Inicio de Sessao

- **Trigger:** Inicio de toda sessao (automatico — NAO esperar usuario pedir)
- **Autonomia:** Nivel 2 (auto-executar SEMPRE)
- **Requer:** Nada (leitura de .context/, Historico de Sessao/, git)
- **Deteccao:** Primeira mensagem, entrada na pasta do projeto, "pop 000", "onde paramos"

## Procedimento

1. Ler CLAUDE.md -> regras e estrutura do projeto
2. Ler SNAPSHOT.md -> estado atual completo
3. `git log --oneline -10` -> timeline recente
4. `git status` -> verificar mudancas nao commitadas
5. Se .env existe -> ler credenciais -> verificar secao Credenciais do MANIFEST
6. Ler ultimo historico de sessao (se houver pasta de historicos)
7. Verificar triggers temporais de outros POPs
8. **Gerar relatorio proativo baseado no projeto:**
   - Analisar TODAS as informacoes coletadas (SNAPSHOT, historicos, git log, docs)
   - Identificar o que e critico, atrasado ou bloqueado
   - Priorizar por: urgencia > criticidade > dependencias > impacto
   - Incluir proximos passos concretos e acionaveis
   - Adaptar formato ao estado real do projeto (sem template fixo)
9. Apresentar ao usuario
10. Perguntar: "Qual sera o foco desta sessao?"

## Criterios de Sucesso

- Diagnostico inteligente apresentado, adaptado ao projeto
- Usuario sabe exatamente onde retomar e o que e prioritario
- Acoes priorizadas por urgencia e criticidade
