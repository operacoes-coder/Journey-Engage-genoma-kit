# deep/ — Investigacoes Profundas

Diretorio para armazenar resultados de investigacoes detalhadas
que excedem o escopo do SNAPSHOT ou DECISIONS.

## Quando usar

- Debug profundo que gera muitos dados
- Auditorias (banco, performance, seguranca)
- Analises comparativas extensas
- Qualquer investigacao que precise de >5k tokens para documentar

## Nomenclatura

- Investigacoes: `inv-NNN-titulo.md`
- Auditorias: `audit-NNN.md`
- Analises: `analise-NNN-titulo.md`

## Nivel de Zoom

Este diretorio corresponde ao Zoom 8 (Atomo) no GENOMA.
So consultar quando os niveis anteriores (0-7) nao resolverem.

Custo estimado: ~30k tokens para leitura completa.
