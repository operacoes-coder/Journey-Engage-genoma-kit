## Decisoes Tomadas

### DEC-001: GENOMA v3.0 com 15 Blocos
- **Decisao:** Evoluir de v2 (7 blocos focados em sessao) para v3 (15 blocos de alta performance)
- **Motivo:** v2 cobria bem o ciclo de sessao (POPs, SNAPSHOT) mas faltavam camadas criticas de specs, calibracao, pontos cegos e orquestracao
- **Impacto:** Assertividade teorica sobe de ~80% (v2) para ~95%+ (v3 preenchido)

### DEC-002: specs/ como diretorio separado de .context/
- **Decisao:** Specs ficam em `specs/` na raiz, nao dentro de `.context/`
- **Motivo:** Specs sao contratos do projeto, nao metadados do framework. Separar permite que times usem specs sem adotar GENOMA completo
- **Alternativa rejeitada:** Tudo dentro de `.context/` — misturaria framework com contratos de negocio

### DEC-003: docs/ para conhecimento evolutivo
- **Decisao:** Criar `docs/` com decisions/, post-mortems/, session-history/
- **Motivo:** ADRs e post-mortems sao "memoria que o Claude nao tem" — eliminam categorias inteiras de erro

### DEC-004: Context Tags ([ALWAYS], [WHEN:x], [REFERENCE], [CALIBRATION])
- **Decisao:** Usar tags no CLAUDE.md para categorizar importancia
- **Motivo:** Context window e limitada — tags permitem ao Claude saber o que e universal vs contextual vs sob demanda

### DEC-005: Glossario como prioridade maxima
- **Decisao:** Glossario e o segundo arquivo lido (apos CLAUDE.md)
- **Motivo:** Ambiguidade de vocabulario causa mais bugs que ambiguidade tecnica. Termo errado no dominio gera implementacao errada.

## Insights Chave da Sessao

1. **Claude opera melhor como tradutor que como gerador** — quanto mais formal a spec, mais assertivo o output
2. **Exemplo concreto > descricao abstrata** — um modulo de referencia vale mais que toda a documentacao
3. **Invariantes eliminam categorias inteiras de bugs** — nao sao regras, sao leis fisicas do dominio
4. **Side effects map e o ponto cego mais perigoso** — sem ele, Claude implementa a acao primaria e esquece as consequencias
5. **Context loading order importa** — o que Claude le primeiro ancora todo o raciocinio subsequente
6. **Session handoff e o que conecta sessoes** — sem ele, cada sessao comeca do zero
